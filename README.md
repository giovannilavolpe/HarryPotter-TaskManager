# HarryPotter-TaskManager
Mateo Roza - Mayra Cueto - Giovanni La Volpe

# CONTEXTO
Una web que toma los datos de HP-API (Harry Potter API) y muestra los personajes de la saga en el menu principal. Los personajes pueden ser taggeados como favoritos, para luego poder filtrarlos. Al pulsar la card de un personaje, muestra un menu de informacion del mismo.

# INICIO DE SESION
La web contiene inicio de sesion persistente con localStorage.

# AJUSTES
La web cuenta con un menu de ajustes, en la cual se puede cerrar sesion.
